LEGACY · 原系统智慧校园

原系统系统业务功能全景

面向教培机构的一体化经营管理 SaaS。以「学员课时」为主线，把招生获客、报名收费、 教务排课、教学交付、家校服务、财务人事串成一条完整业务链，并提供经营数据看板与 AI 辅助能力。

账号机构：幻彩教育 系统版本：v13.0 PC 端：pro.legacy.cn/web 业务规模：2 校区 / 1333 在读学员 梳理时间：2026-10-17

业务主线

系统所有功能都围绕这条链路设计，任何模块的数据最终都汇入「课时账户」和「财务流水」。

获客引流→ 咨询跟进→ 报名收费→ 分班排课→ 上课记课时→ 作业点评→ 续费/转退→ 经营报表

使用要点

  • 权限是分级的。当前账号可访问绝大部分模块，但「招生中心 → 咨询本」提示无权限，说明线索数据对非招生角色隔离。需要时可让管理员在「内部管理 → 员工 → 角色管理」中分配。
  • 多校区是同一套系统内的数据隔离。鲅鱼圈、新民两个校区共用一个后台，通过「管辖校区」和报表的「校区对比」做分流统计。
  • 课时是核心资产。学员的剩余课时由「报名 → 排课 → 记上课」驱动扣减，工作台提示「按课时学员将到期 855 位」是最重要的续费信号。
  • 记上课必须及时。今日 17 条待记录，未记上课会导致课时消耗和教师工资核算失真，也会让家长端看不到上课记录。
  • 家长端靠「家长端」承载。点评、作业、通知、成长记录都通过微信推送给家长，是续费转化的主要触点。
  • 升级项决定能力上限。AI 学员运营、AI 风险预警、人脸考勤、错题本、积分商城、美团/抖音/小红书直连均为升级功能，当前版本未开通的部分会显示「升级」标记。
  • 数据可导出。学员、班级、订单、财务、员工等列表页均支持「导出当前结果」和「自定义显示列」，方便二次分析。

什么是「升班」

与「分配学员」的区别：升班是按学期整班迁移，会生成批次记录并处理原班留档。

操作适用场景原班记录可追溯
分配学员零散加人、临时调班直接移出原班无批次
升班新学期整班升级、一带多分流已升班 / 欠费保留在读 / 不念留档有批次与明细

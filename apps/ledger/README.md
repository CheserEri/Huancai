# 幻彩课时记账系统

私用、内网、不备案、不需要公网域名的课时记账工具。
零第三方依赖（只用 Python 自带的库），数据存本地一个 SQLite 文件。

---

## 一、怎么启动

1. 双击 **`启动.bat`**
2. 看到窗口里打印出两个地址，就说明启动成功了
3. 用浏览器打开 `http://127.0.0.1:8000`

关掉那个黑窗口 = 停止服务。数据不会丢，下次再启动还在。

> 如果提示"启动失败，可能没有安装 Python"：去 https://www.python.org/downloads/ 下载安装，
> 安装时**务必勾选 `Add Python to PATH`**。

## 二、局域网怎么访问

启动后窗口里会显示一个 `http://192.168.x.x:8000` 的地址。
**同一 WiFi 下的电脑、手机、平板**，浏览器直接打开这个地址就能用。

家长也可以在自己手机上打开 `http://192.168.x.x:8000/parent` 查课时——
但前提是手机连着校区的 WiFi。**离开这个网络就访问不了**（这是"不备案、不用公网域名"的必然结果）。

如果哪天要让家长在外面也能查，只有两条路：
- 内网穿透（如 frp / 花生壳），本质是借一个公网地址
- 备案域名 + 公网服务器

## 四、功能

### 看板
在读学员数、在读报读数、剩余课时合计、本月实收、应收未收、30 天内到期数，以及最近订单。

### 学员
- 左侧搜索（姓名 / 手机号），右侧看该学员的报读与课时
- **记 1 / 0.5 / 2 课时**：一键扣课时，自动写流水
- **退费试算**：按「实收 ÷ 总课时」算折后单价，算出已消耗金额和应退金额
- **+ 报读 / 充值课时**：填课程、课时、赠送课时、实收、有效期，保存后自动生成报名流水 + 一笔订单

### 订单
全部订单流水，含应收、实收、优惠、收款方式、经办人。

### 到期预警
按 30 / 60 / 90 天筛选即将到期的报读记录，可直接跳到学员详情跟进续费。

### 家长查询 `/parent`
家长输入「学员姓名 + 报名时预留手机号后四位」，查看各课程剩余课时与到期日。
**只读**，不能做任何修改。

## 五、退费口径

```
折后单价 = 实收金额 ÷ 总课时（赠送课时不计入分母）
已消耗金额 = 已消耗课时 × 折后单价
应退金额 = 实收金额 − 已消耗金额
```

如果机构有自己的手续费、优惠分摊或赠送课时折算规则，以这个结果为基础人工调整。
**这套口径写在代码里，改起来只需要动 `app.py` 的 `enroll_view()` 函数。**

## 六、数据与备份

- 所有数据在 **`data.db`** 这一个文件里
- **备份 = 复制 `data.db`**，拷到 U 盘或网盘即可
- 恢复 = 把备份文件改回 `data.db` 覆盖
- 想清空重来 = 删掉 `data.db`，重启服务会自动重建空库

建议每周备份一次，文件名带上日期，比如 `data-2026-10-17.db`。

## 七、已知限制（重要）

| 限制 | 说明 |
|---|---|
| **不能连校宝** | 校宝没有开放 API，数据只能在这个系统里独立记账，不会自动同步 |
| **家长端只在局域网可用** | 没备案、没公网域名，家长连校区 WiFi 才能查 |
| **单机运行** | 同时多人在局域网用没问题，但服务依赖启动的那台电脑，那台电脑关机就停了 |
| **没有登录密码** | 内网私用，默认不设账号。如果要防同事误操作，可以后续加一个简单口令 |
| **没有权限分级** | 所有能打开页面的人都能改数据 |

## 九、想加功能怎么办

这个版本刻意只做了「课时 + 订单 + 退费」三件事。
如果要加，按投入从小到大：

1. **排课表**：加一张 `lesson` 表，按班级生成课次，上课时从课次扣课时
2. **导出 Excel**：加一个 `/api/export` 接口，用 `csv` 模块输出
3. **登录口令**：加一个中间件，校验一个固定 token
4. **校宝数据导入**：写一个解析校宝导出 Excel 的脚本，批量灌入学员和课时
